Tema 1

¿Qué es una GUI?

GUI significa Interfaz Gráfica de Usuario. Es la parte visual de una aplicación con la que una persona interactúa: textos, imágenes, botones, formularios, menús, tablas, gráficos y ventanas.

HTML

Construye la estructura de la página: títulos, párrafos, botones, tablas, formularios y demás elementos.

CSS

Controla la apariencia: tamaños, espacios, bordes, tipografía, distribución y adaptación a diferentes pantallas.

JavaScript

Agrega comportamiento: responder a botones, validar datos, tomar decisiones y modificar la interfaz.

Idea clave: HTML crea, CSS presenta y JavaScript hace que la interfaz responda.
Tema 2

Texto

El texto permite comunicar información y organizar visualmente el contenido.

Ejemplo

Encuentra dispositivos y accesorios para tus necesidades.

Oferta especial esta semana.

Código HTML

<h1>Mi tienda tecnológica</h1> <h3>Productos disponibles</h3> <p>Encuentra dispositivos y accesorios.</p> <strong>Oferta especial esta semana.</strong>
Reto: crea un título, un subtítulo, dos párrafos y una frase importante en negrita.
Tema 3

Imágenes

Las imágenes deben apoyar el mensaje y no estar colocadas solamente como decoración.

Código HTML

<img src="imagenes/computadora.jpg" alt="Computadora de escritorio" width="300" >

src: indica dónde está la imagen.

alt: describe la imagen si no se puede ver.

width: define un ancho básico.

Tema 5

Botones e interacción

Los botones permiten que el usuario provoque una acción dentro de la aplicación.

Pruébalo

Todavía no has presionado el botón.

JavaScript

function cambiarMensaje() { document.getElementById("buttonMessage") .textContent = "¡El botón fue presionado!"; }
Cuando el usuario hace clic, ocurre un evento. JavaScript puede responder a ese evento.
